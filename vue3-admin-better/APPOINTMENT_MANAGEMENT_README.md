# 预约管理系统 - 管理员后台

## 📋 功能概述

预约管理系统是宠物家管理员后台的核心功能模块，提供完整的预约服务管理能力，包括预约的创建、查看、编辑、删除和状态管理。

## 🎯 主要功能

### 1. 预约管理
- **预约列表**：分页显示所有预约信息
- **预约详情**：查看预约的完整信息
- **新增预约**：管理员为用户创建新预约
- **编辑预约**：修改预约信息
- **删除预约**：删除不需要的预约记录

### 2. 状态管理
- **待确认**：新创建的预约状态
- **已确认**：商家确认的预约
- **已完成**：服务完成的预约
- **已取消**：取消的预约

### 3. 数据筛选与搜索
- **状态筛选**：按预约状态筛选
- **日期范围**：按预约日期范围筛选
- **关键词搜索**：支持客户姓名、宠物名称、服务类型搜索
- **智能排序**：按创建时间、预约时间排序

### 4. 统计与分析
- **状态统计**：各状态预约数量统计
- **服务类型统计**：不同服务类型的预约统计
- **数据导出**：支持CSV格式数据导出

## 🛠️ 技术实现

### 前端技术栈
- **Vue 3**：现代化的JavaScript框架
- **Element Plus**：企业级UI组件库
- **Axios**：HTTP请求库
- **Vue Router**：路由管理

### 后端API接口
- **RESTful API**：标准的REST接口设计
- **Spring Boot**：Java后端框架
- **MyBatis Plus**：数据访问层
- **MySQL**：关系型数据库

## 🚀 快速开始

### 1. 环境要求
- Node.js 16+
- Vue 3
- 宠物家后端服务（端口8080）

### 2. 启动步骤
1. 启动后端服务
2. 启动前端开发服务器
3. 访问 `/services/appointments` 路由

### 3. 权限配置
预约管理功能需要管理员权限，确保用户具有相应权限。

## 📊 API接口文档

### 预约管理接口
- `POST /api/appointment/create` - 创建预约
- `PUT /api/appointment/update/{id}` - 更新预约
- `DELETE /api/appointment/delete/{id}` - 删除预约
- `GET /api/appointment/detail/{id}` - 获取预约详情
- `POST /api/appointment/list` - 分页查询预约列表

### 状态管理接口
- `PUT /api/appointment/merchant/confirm/{id}` - 确认预约
- `PUT /api/appointment/merchant/cancel/{id}` - 取消预约
- `PUT /api/appointment/merchant/complete/{id}` - 完成预约

### 统计接口
- `GET /api/appointment/statistics/status` - 获取状态统计
- `GET /api/appointment/statistics/service` - 获取服务类型统计
