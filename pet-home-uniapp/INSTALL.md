# 宠物之家项目安装指南

## 环境要求

- HBuilderX 3.0+
- Node.js 14.0+
- 微信开发者工具（用于小程序调试）

## 快速开始

### 1. 导入项目

1. 打开 HBuilderX
2. 点击「文件」→「导入」→「从文件夹导入」
3. 选择 `pet-home-uniapp` 文件夹
4. 等待项目加载完成

### 2. 安装依赖

项目已包含所有必要依赖，无需额外安装。

### 3. 运行项目

#### 微信小程序运行
1. 在 HBuilderX 中打开项目
2. 点击顶部工具栏的「运行」按钮
3. 选择「运行到小程序模拟器」
4. 或选择「真机运行」进行真机调试

#### 浏览器H5运行
1. 在 HBuilderX 中打开项目
2. 点击顶部工具栏的「运行」按钮
3. 选择「运行到浏览器」
4. 自动打开浏览器访问项目

## 项目特色

✅ **完整功能**
- 首页轮播、商品展示、分类导航
- 用户登录注册、个人中心

- 购物车功能、订单管理

- Vue 2.x + uniapp 跨平台框架

- Vuex 状态管理
- SCSS 样式预处理

✅ **完整后端接口**
- 基于你的后端API设计
- 支持用户认证、商品管理、订单流程
- 预约服务、宠物管理等完整功能

## 开发说明

### 后端接口地址
项目默认连接 `https://localhost:8080`，请确保你的后端服务正常运行。

### 样式主题
项目使用橙色主题 `#ff6b35`，可在 `common/css/variables.scss` 中修改。

### 组件使用
项目使用 uView 组件库，支持按需引入，无需手动导入组件。

### 状态管理
使用 Vuex 管理全局状态，包括用户信息、购物车等。

## 注意事项

1. **首次运行**：如遇到依赖问题，请重启 HBuilderX
2. **真机调试**：需要配置合法域名 `https://localhost:8080`
3. **样式编译**：项目使用 SCSS，如有语法错误请检查文件格式
4. **组件报错**：确保 uView 库正确引入

## 故障排除

### 常见问题

**Q: uView组件不显示？**
A: 检查 `pages.json` 中的 easycom 配置是否正确。

**Q: 样式不生效？**
A: 检查 SCSS 文件语法，确认 `@import` 路径正确。

**Q: 后端接口报错？**
A: 确认后端服务运行在正确端口，检查接口地址配置。
