# 宠物之家项目快速开始指南

## 🎯 项目简介

宠物之家是一个基于uniapp开发的宠物服务平台，支持微信小程序、H5等多端部署。

## 🚀 快速开始

### 1. 环境要求

- **HBuilderX 3.0+**
- **Node.js 14.0+**
- **微信开发者工具**（用于小程序调试）

### 2. 项目导入

1. 打开 **HBuilderX**
2. 点击菜单栏：**文件** → **导入** → **从文件夹导入**
3. 选择项目文件夹：`pet-home-uniapp`
4. 等待项目加载完成

### 3. 运行项目

#### 微信小程序运行
1. 在HBuilderX中打开项目
2. 点击顶部工具栏的**运行**按钮
3. 选择**运行到小程序模拟器**
4. 或选择**真机运行**进行真机调试
5. **直接查看个人主页**：访问"我的"页面即可看到完整的设计效果，无需登录

## 🔧 技术栈

- **框架**：uniapp (Vue 2.x)
- **UI库**：原生uni-app组件
- **状态管理**：Vuex
- **样式**：SCSS
- **后端接口**：RESTful API

## ⚙️ 配置说明

### 后端接口地址
项目默认连接 `https://localhost:8080`，请确保你的后端服务正常运行。

### 样式主题
项目使用橙色主题 `#ff6b35`，可在 `common/css/variables.scss` 中修改。

### 状态管理
使用 Vuex 管理全局状态，包括用户信息、购物车等。

## 📖 开发说明

### 目录结构
```
pet-home-uniapp/
├── pages/           # 页面文件
├── common/          # 公共资源
│   ├── css/        # 样式文件
│   └── js/         # 工具函数和API
├── components/      # 公共组件
├── store/          # 状态管理
├── static/         # 静态资源
└── 核心配置文件   # main.js, pages.json等
```

### 组件使用
项目使用原生uni-app组件，无需额外依赖，按需引入即可。

### API调用
项目已封装完整的API接口，可在 `common/js/api.js` 中查看。

## 🔍 故障排除

### 常见问题

**Q: 项目无法运行？**
A: 检查HBuilderX版本，确保在3.0以上版本。

**Q: 样式不生效？**
A: 检查SCSS文件语法，确保所有插值语法都已修复。

**Q: 后端接口报错？**
A: 确认后端服务运行在正确端口，检查接口地址配置。

**Q: 组件报错？**
A: 确保所有uView组件都已替换为原生uni-app组件。
