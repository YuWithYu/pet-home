# 图标文件说明

## 📁 图标文件位置

小程序tabBar图标文件应放在：`static/images/` 目录下

## 🎯 需要的图标文件

项目需要以下8个图标文件：

### 首页图标
- `home.png` - 首页图标（灰色）
- `home-active.png` - 首页选中状态图标（橙色）

### 分类图标
- `category.png` - 分类图标（灰色）
- `category-active.png` - 分类选中状态图标（橙色）

### 购物车图标
- `cart.png` - 购物车图标（灰色）
- `cart-active.png` - 购物车选中状态图标（橙色）

### 我的图标
- `user.png` - 我的图标（灰色）
- `user-active.png` - 我的选中状态图标（橙色）

## 📏 图标规格要求

- **尺寸**：建议 48x48 像素或 64x64 像素
- **格式**：PNG格式（支持透明背景）
- **颜色**：
  - 未选中状态：灰色 (#7A7E83)
  - 选中状态：主题色 (#ff6b35)

## 🛠️ 图标制作建议

### 方法1：使用在线工具
推荐使用以下在线工具制作图标：
- [阿里巴巴矢量图标库](https://www.iconfont.cn/)
- [Flaticon](https://www.flaticon.com/)
- [Icons8](https://icons8.com/)

### 方法2：使用设计软件
- Adobe Illustrator
- Sketch
- Figma

### 方法3：使用现有图标
从网上下载免费的小图标素材，修改颜色即可。

## 🎨 颜色搭配建议

- **未选中**：#7A7E83 (灰色)
- **选中**：#ff6b35 (橙色主题色)
- **背景**：白色或浅灰色

## 🔄 如何添加图标

目前项目使用默认文本图标。如需添加自定义图标：

1. **准备图标文件**：
   - 格式：PNG格式
   - 尺寸：48x48 或 64x64 像素
   - 颜色：灰色（未选中）和橙色（选中）

2. **放置图标文件**：
   ```
   static/images/
   ├── home.png          # 首页图标
   ├── home-active.png   # 首页选中状态
   ├── category.png      # 分类图标
   ├── category-active.png # 分类选中状态
   ├── cart.png          # 购物车图标
   ├── cart-active.png   # 购物车选中状态
   ├── user.png          # 用户图标
   └── user-active.png   # 用户选中状态
   ```

3. **修改配置**：
   编辑 `pages.json` 文件，添加图标路径：
   ```json
   "list": [
     {
       "pagePath": "pages/index/index",
       "iconPath": "/static/images/home.png",
       "selectedIconPath": "/static/images/home-active.png",
       "text": "首页"
     }
     // ... 其他页面配置
   ]
   ```

4. **重新编译运行**项目即可看到新图标

## 📱 图标预览

替换图标后，tabBar底部应该显示：

```
[首页图标]    [分类图标]    [购物车图标]    [我的图标]
```

## ⚠️ 注意事项

1. **图标大小**：建议不要超过64x64像素，避免显示过大
2. **文件格式**：必须是PNG格式，支持透明背景
3. **路径问题**：确保图标路径配置正确，目前配置为 `/static/images/文件名.png`
4. **缓存问题**：更换图标后可能需要清除缓存或重新编译

## 🚀 快速开始

如果你不想制作图标，可以：

1. **临时方案**：将现有的占位符图标复制重命名
2. **推荐方案**：从网上下载现成的图标素材
3. **专业方案**：使用专业的UI设计师制作
